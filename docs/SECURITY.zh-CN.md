# 自动主题加载与本机连接的安全加固

[实现过程](IMPLEMENTATION.zh-CN.md) · [自动加载说明](AUTO-THEME.zh-CN.md)

## 本次变更

- 新建、关闭标签页使用明确的 UI Automation 按钮，不再发送 Ctrl+T、Ctrl+L、Ctrl+W 或清理用的 Esc。跟踪临时标签页的运行时身份，标签页变化即停止。
- 地址栏必须属于浏览器界面，位于网页文档之外，名称和进程匹配且唯一。填写后再次核对焦点、控件身份和文字，只向确认后的地址栏发送回车。内部页面优先提供匹配的文档 URL；缺少此能力时还必须核对对应内部页面标题、地址栏与临时标签页身份。无法确认时停止，不降级为坐标点击。
- 发送回车前检查键盘和鼠标按钮是否仍被按住。自动输入携带确定的时间戳，之后核对最后输入时间，不再把任意最新输入吸收到自动化基准中。
- 文件夹选择框必须同进程、通过窗口归属链属于目标浏览器，并且只有一个候选。输入框、确认按钮也必须唯一，填写后核对路径。
- 加载期间以只读共享方式持有主题 manifest 文件，允许浏览器读取，阻止其他进程改写、删除或替换；限制文件大小，拒绝目录链和文件中的链接、重定向，加载前后复核内容。
- 出错后不再自动发送关闭或取消按键。已经开始操作时停止后续浏览器，用户可以在覆盖结束后处理残留临时页面。
- 本机背景服务要求 256 位随机连接密钥。密钥由 Windows 当前用户数据保护机制加密保存，扩展连接配置只生成于本机。请求密钥不放进网址，也不写入日志、预览图或发布包。
- 服务核对请求方法、Host、密钥与扩展来源格式，拒绝重复的关键请求头、不完整或过大的头部，并限制同时连接数。它仍只监听回环地址，提供只读背景与配色。

## 升级步骤

1. 退出旧软件，启动安全加固版。
2. 在软件「浏览器联动」点击对应浏览器的安装按钮。
3. 当前修复版会优先更新已安装的 DeskShift 扩展原目录，保留身份与网址设置；关闭旧新标签页并重新打开。如原目录不可写，再按指南加载个人数据目录中的连接版扩展。详见 [连接与指针修复](REPAIR.zh-CN.md)。

该目录由软件生成连接配置，后续软件版本继续更新同一目录。程序旁的浏览器文件是模板，没有连接密钥，不能直接用于新版服务。连接密钥在软件重启后保持，不需要每次配对。若卸载后删除了个人数据目录，则需重新生成并加载扩展。

由于加载目录改变，浏览器可能把它视为新的扩展；旧目录中的手动网址设置可能需要重新添加。旧扩展与本地数据不由软件自动删除。

## 验证

软件自检验证：主题加载锁确实阻止写入和删除但允许读取；密钥加密保存并跨重启复用；生成的本地扩展拿到配置；无密钥、错误密钥、非法来源、重复密钥请求均被拒绝；合法请求与背景修订检查仍有效。浏览器测试覆盖 Chrome / Edge 在线、离线同步和请求携带密钥；没有连接配置时不向本机服务发起请求。页面预览采用测试密钥，不使用真实用户配置。

普通测试不等于真实浏览器的安全认证。本次没有通过自动化在日常浏览器里安装主题，也没有确认 Chrome 自动加载成功。更严格的识别可能让某些浏览器版本停止加载，此时可以使用手动指南。

## 仍然存在的边界

全屏遮罩不是安全隔离。回车仍通过 Windows 输入流发送，焦点检查与发送间的极短间隙，以及同一时间戳粒度内的用户输入，不能完全排除。UI Automation 调用可能被浏览器阻塞，超时会撤去遮罩并请求取消，但不能强制终止已进入的控件调用。

密钥防止没有凭据的本地请求和其他扩展随意读取背景，但不用于抵御已取得当前用户权限的恶意软件：该软件可能读取本地扩展文件，也能调用当前用户的数据解密功能。开发者模式仍须用户事先开启。程序不请求管理员权限、不开放调试端口、不绕过 Windows 焦点限制、不自动重启浏览器。

运行前版本保留在本机 `backups/before-security-20261011-150720/`。关闭自动加载可停用主题自动化；回退旧软件时，使用旧版对应的扩展目录。
