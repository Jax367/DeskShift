# DeskShift 桌面随心换

[返回项目首页](../README.md) · [English](../README.en.md) · [日本語](../README.ja.md)

作者：Lar · 联系邮箱：turelar367@gmail.com

Windows 10/11 桌面程序。已内置用户提供的三张壁纸；导入新图片时自动提取主色、五色调色板和明暗方案。

## 开始使用

「切换设置 → 桌面快捷入口 → 显示桌面悬浮球」可开启快捷入口，默认关闭。悬浮球支持拖动并记住位置；点击展开带缩略图与配色的壁纸列表，选择后按当前设置切换。右键可以打开主窗口或隐藏，点击面板外部或 Esc 收起。导入新图片后，再次展开时会自动加入。切换期间暂时隐藏，完成后恢复；主窗口收起到托盘时仍可使用，退出程序后移除。

双击 `DeskShift.exe`（源码目录中为 `dist\DeskShift.exe`）。选择壁纸，点击「一键应用桌面」。Windows 会应用填充模式壁纸、主色、窗口强调色及浅色/深色模式。系统配色仅通过白名单设置更新，不加载整套 Windows 主题，不更改光标方案、鼠标灵敏度、声音、桌面图标或视觉样式；无需管理员权限。开始菜单与任务栏强调色在 Windows 浅色模式中不受支持。部分应用需重新打开才能显示新的明暗模式。

- 点击「添加壁纸」或将 JPG、PNG、BMP 拖入窗口；导入后图片会复制到个人壁纸库，原文件可以移动。
- 点击「调整主色」修正自动取色；明暗模式可选自动、浅色、深色。
- 取消「同步 Windows 配色」可仅切换壁纸并发布浏览器配色。
- 选择壁纸或修改配色时，预览使用约 220 毫秒的淡入过渡。应用、撤销在后台运行，底部动画显示正在处理，切换期间可以移动窗口或收起到托盘。桌面图片按原始分辨率无损缓存，不缩小、不重采样，重复切换直接复用。预览缩略图只用于窗口显示，不用于设置桌面。浏览器使用纯颜色主题，需手动加载；不会替换现有页面。
- 默认启用「全屏过渡」，提供斜向扫幕、对开幕帘、交错条带、圆形扩散和方格翻涌。默认随机且不连续重复，可以在「过渡效果」中固定选择。先在后台准备原尺寸图片、主题文件、文件读取缓存，以及每个显示器的动画背景和遮罩帧，再开始约 500 毫秒覆盖。完全遮住后执行切换，等待壁纸设置稳定约 450 毫秒和本程序的 DWM 更新同步，然后约 650 毫秒揭幕；系统较慢时等待操作返回，不再因为固定动画时间到了提前揭幕。遮罩不显示文字中间页，等待阶段中央随机展示六种几何设计动画：轨道光环、无限回环、模块矩阵、节奏波列、呼吸花环、折叠棱镜。每次切换独立随机且不连续重复，多显示器保持同款同步，配色跟随壁纸。只预生成当前选中的动画，按 30 帧每秒循环，等待时仅重绘小块区域；切换完成即揭幕，不额外等待动画播完。12 秒超时保护仍可撤去覆盖。在程序拥有键盘焦点时 Esc 可以跳过动画，也可取消勾选「全屏过渡」。全屏过渡遵循系统动画设置。
- 「下一张」立即应用下一张壁纸。关闭窗口会收起到托盘，双击托盘图标重新打开。右键托盘图标，在「切换壁纸」子菜单中直接选择图片，会按当前设置应用壁纸、配色与过渡动画；当前使用的壁纸显示勾选标记，新导入的图片自动加入菜单。切换期间相关菜单项暂时禁用。右键菜单也可切换下一张、撤销或退出。
- 「撤销上次切换」恢复上一次切换前的壁纸及程序修改的注册表值。只能撤销一步；切换备份会跨程序重启保留。壁纸恢复依赖原壁纸文件仍存在。撤销仅恢复壁纸和配色白名单中的值，不恢复或写入鼠标与光标设置；个别 Windows 版本的强调色刷新可能需要重新打开应用或注销。

## 简洁新标签页

点击「添加网址」手动输入名称和地址，未填协议时自动补 HTTPS。手动添加优先显示，默认根据访问记录自动推荐以补齐剩余位置，总共最多 8 个网址。悬停卡片点击「⋯」可编辑、删除或隐藏自动推荐。取消「根据访问记录自动补充网址」可只用手动列表；「恢复隐藏推荐」恢复曾隐藏的网站。设置仅保存到当前浏览器扩展的本地存储，不发送给桌面程序，关闭软件或重启浏览器后仍保留。


软件「浏览器联动」中打开安装指南，在 `chrome://extensions` 或 `edge://extensions` 加载软件生成的 `%LOCALAPPDATA%\DeskShift\browser-extensions\chrome` 或 `edge` 连接版扩展（程序旁的文件是未配对模板）。安装会替换新标签页，保留原有启动页地址和首页按钮地址。旧新标签页扩展可以重新加载；此前装过纯配色主题时，请单独安装这份新标签页扩展。

页面只有所选背景、搜索和最多 8 个最常访问的网站，去掉时间、日期、新闻和宣传文字。常用网址来自浏览器 `topSites`，不申请完整 `history` 权限，列表不发给桌面程序或服务器。没有访问记录时显示提示，网址列表可能不同于默认 Edge 的置顶快捷方式。

在「切换设置 → 浏览器背景 → 背景样式」选择「压缩原图」「亚克力模糊」或「抽象色块」，选择后自动同步浏览器背景。压缩原图保留画面；亚克力模糊柔化细节并叠加明暗遮罩和颗粒；抽象色块仅用壁纸调色板绘制大曲线和色块，不保留人物、建筑或轮廓。背景从本机只读服务获取，使用独立 JPEG 副本（最长边 2560 像素、质量 82），不修改桌面原图，仅缓存最近一张。离线保留最近壁纸，隐藏标签页停止轮询。Chrome 搜索 Google，Edge 搜索 Bing。扩展可以停用或移除，以恢复原有新标签页。完整标签栏颜色仍需导出主题并手动加载。

## 动画预热

动画启动优化：程序打开后会在隐藏状态预热全屏窗口、原生窗口句柄和首次绘制。每次切换先准备当前效果，等各显示器的首帧绘制返回并交还界面消息循环，再启动动画计时，避免初始化耗时吃掉开场动画。全屏窗口按显示器位置和尺寸复用；背景、遮罩、等待帧按尺寸、配色和效果缓存。不同显示器共享同一份等待帧，缓存采用约 160 MiB 的预算和最近使用淘汰，正在播放的资源不会被回收。此预算不包含窗口缓冲等系统内存。上述优化不改变桌面原图分辨率，也不能保证系统或显卡呈现完全没有停顿。

仅启动程序、选择壁纸或导入图片不会改变系统设置。配色和图片在本地处理。数据放在 `%LOCALAPPDATA%\DeskShift`，包含壁纸库、切换前备份、主题导出和壁纸 BMP。卸载时先关闭自启、撤销切换，再退出程序并删除该目录与程序目录。

「切换设置 → 启动」可以创建桌面快捷方式、开启或关闭开机自启。默认不自启；开启后登录 Windows 时在托盘运行，不自动切换壁纸，仅登记当前用户的 DeskShift 启动项。软件目录移动后，重新创建快捷方式并重新开关自启。「明暗模式」选择跟随壁纸时自动切换浅色 / 深色；固定模式会覆盖壁纸明暗，更改选项后立即应用当前壁纸。

## 构建和验证

软件包含专属图标，统一用于可执行文件、窗口、任务栏与系统托盘。

不依赖 NuGet、Python 或 Node。使用 Windows 自带 .NET Framework 4.x C# 编译器与 Windows Forms / GDI+。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
$p = Start-Process .\dist\DeskShift.exe -ArgumentList '--self-test' -Wait -PassThru
$p.ExitCode
Start-Process .\dist\DeskShift.exe -ArgumentList '--smoke' -Wait
```

测试输出位于 `test-output`。自测验证初始图片取色、文字对比度、导入与持久化、主题格式、悬浮球设置以及浏览器主题的页面保护；`--smoke` 生成窗口预览截图。上述命令不会切换真实桌面。实际 Windows 主题与 Chrome 安装效果需要在目标系统上确认。

## 实现与接口

`src/Core.cs`：160×100 像素采样、RGB 分桶、色彩覆盖率与饱和度加权取色；浅色背景不会压过全部彩色主体。`src/WindowsTheme.cs`：SPI_SETDESKWALLPAPER、当前用户配色注册表白名单与备份，不调用整套 Windows 主题引擎。`src/App.cs`：预览、壁纸库、导入及托盘。`src/DesktopTransition.cs`：不抢焦点的多显示器全屏过渡，提前缓存背景与遮罩帧。Windows 没有统一的所有应用主题渲染完成信号；本程序检查壁纸设置稳定并给刷新留出时间，DwmFlush 仅同步本程序的排队更新，不能保证其他应用或整个会话已经渲染完毕。

扩展仅申请存储、最常访问网站和本机连接权限；只读服务检查 Host、Origin 和壁纸版本，不编辑浏览器配置文件。原始图片保留在 `assets\wallpapers`。

接口参考：[Chrome 官方主题文档](https://developer.chrome.com/docs/extensions/develop/ui/themes)、[Windows SystemParametersInfo](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-systemparametersinfow)、[WM_SETTINGCHANGE](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-settingchange)。

渲染同步参考：[DwmFlush 官方文档](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmflush)。

等待动效为本项目原创几何绘制，设计参考：[MetaLab 几何加载动效](https://dribbble.com/shots/4037784-Geometric-shapes-loading-animation)、[Nick Buturishvili 的 Infinity Loader](https://dribbble.com/shots/2465356-Infinity-Loader)、[IBM 动效技巧](https://www.ibm.com/design/language/animation/tips-and-techniques/)。

网站快捷方式使用浏览器保存的原站 favicon，不再生成字母图标。更新扩展后，请在扩展管理页重新加载，并允许 favicon 权限。网址列表紧贴搜索框下方居中排列。标题栏配色请在软件的「标题栏配色指南」中按步骤单独加载；新标签页连接成功不代表标题栏主题已加载。
