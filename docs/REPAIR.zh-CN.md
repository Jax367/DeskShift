# 指针、界面配色与浏览器连接修复

本次修复保持 Windows 配色白名单，不加载整套系统主题，也不修改鼠标速度、加速度或滚轮设置。

## 自定义指针

切换和撤销时记录当前用户的指针方案。若本次操作期间方案被改变且未检测到人工输入，恢复切换开始时的方案并让 Windows 重新读取指针；不使用旧撤销记录覆盖后来选择的方案。没有变化时不写指针设置。

软件自身的按钮、卡片、悬浮球及覆盖窗口读取当前方案的 Arrow / Hand 文件，支持 CUR 和 ANI，避免应用控件使用此前缓存的默认指针。此功能保留当前方案，无法推断在旧版本中已经丢失且没有备份的自定义方案。

## 设置界面

主窗口和设置卡片跟随当前已应用壁纸的调色板；尚未应用时使用所选壁纸。背景、侧栏、卡片、文字、按钮、开关和选择框支持浅色、薄荷色、深色。窗口标题栏在系统支持时使用同样的配色，仅作用于 DeskShift 自己的窗口。

明暗模式显示为「跟随壁纸 / 固定浅色 / 固定深色」。固定模式会覆盖图片自动识别的明暗；希望切换浅色和深色壁纸时自动变化，请使用「跟随壁纸」。更改模式时立即重新应用当前壁纸，并同步 Windows 应用模式和系统模式（需开启同步 Windows 配色）、软件配色与浏览器新标签页；标题栏主题仍按原来的自动加载选项执行。

设置中的「启动」提供开机自启开关与创建桌面快捷方式按钮。自启只在当前用户的登录启动项中登记 DeskShift，使用带引号的程序路径及 `--startup` 参数，不需要管理员权限；关闭时只移除 DeskShift 的启动项。未登记时默认关闭。登录启动后隐藏主窗口并在托盘运行，不自动应用壁纸或系统配色；已有实例时安静退出。桌面快捷方式使用当前程序内置图标，软件目录移动后请重新创建快捷方式并重新开关自启。

## 浏览器原目录修复

排查时仍在运行 `dist-background-styles` 旧版，两个浏览器加载的都是项目原 `browser/chrome` 和 `browser/edge` 目录。安全版更换了服务连接协议，却只在另一个目录生成连接配置，原扩展无法同步。

修复版读取 Chrome / Edge 各配置目录中的扩展路径，只更新 manifest 名称、浏览器类型和 newtab.html 覆盖匹配的 DeskShift 新标签页扩展，拒绝链接或重定向目录，不改浏览器 Preferences。更新原文件夹可保持扩展身份、手动网址和隐藏推荐记录。纯配色主题以及其他扩展不作为更新目标。

原目录写入新的页面文件和本机密钥配置。新标签页发现 manifest 版本过旧时，通过自己的 runtime.reload 更新扩展，每个版本最多尝试一次，失败时提示重新加载，不循环重启。已有页面可能仍缓存旧脚本，需要关闭旧新标签页并重新打开；浏览器已停用的扩展仍需用户启用。

设置页的「修复浏览器连接」可以再次更新配置。无法写入原目录时，才使用安装指南中的个人数据目录。连接仍要求随机密钥，不降级成匿名读取背景。

## 标题栏加载

部分浏览器的 UI Automation 文档不提供 URL 值，旧安全版会因此直接停止。修复版优先检查文档 URL；缺少该能力时，必须同时满足已验证的浏览器地址栏、临时标签页身份和对应内部页面标题。焦点、用户输入、主题文件锁、文件夹归属及超时保护继续生效。

这只是识别兼容性修复，不代表 Chrome / Edge 实机自动加载已确认成功。新标签页同步和顶部标题栏主题加载仍是两个流程；浏览器主题被停用或尚未加载时，要按标题栏配色指南处理。

## 验证与备份

自检验证自定义 ANI 路径的恢复计划、无变化时不写入、原目录更新保留其他文件、仅匹配正确浏览器的 DeskShift 新标签页。浏览器测试覆盖在线、离线、密钥缺失、旧 manifest 自更新与防重载循环；隔离页面完成背景渲染。浅色、薄荷色与深色设置页已生成预览。

源码和浏览器模板的修改前备份位于本机 `backups/before-integration-repair-*/`（具体目录名以本机记录为准），不进入发布包。软件更新时只重启 DeskShift，不自动关闭浏览器或切换桌面。
