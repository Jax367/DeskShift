# 覆盖期间自动加载标题栏主题（试验）

此功能默认关闭。软件中的「浏览器联动 → 标题栏自动加载 · 试验」可选择 Chrome 或 Edge 并开启。

开启前，需要浏览器已有开发者模式、只打开一个浏览器窗口，并使用 Default 配置。其他配置和多个窗口会停止或跳过自动加载。全屏过渡也必须开启，且系统允许动画。

应用壁纸时，软件先完成全屏覆盖，再打开临时标签页核对浏览器配置、进入扩展页并加载纯配色主题。确认主题目录生效后，关闭临时页、恢复焦点并揭幕。浏览器背景与桌面壁纸的清晰度策略保持不变。

自动化不开放远程调试端口、不写浏览器 Preferences、不使用剪贴板或全局输入监听、不自动开启开发者模式。只有固定颜色字段、有效 RGB 和没有运行时权限的主题可以加载。每种配色使用独立主题目录，避免旧缓存。

系统拒绝焦点切换、用户输入、未知控件、窗口变化或超时会停止自动化。加载尝试最多约 7 秒；过渡本身仍有 12 秒保护。失败时可能留下临时页面或文件选择框，用户可以手动关闭。为避免错误操作，取消后不会继续发送关闭窗口的按键。

独立 Edge 测试的实际结果：Windows 拒绝后台测试程序取得浏览器焦点，保护机制停止加载。尚未验证完整加载流程成功，也未在日常浏览器配置中启用或执行；不能视为稳定功能。普通软件自检与主题验证用于确认默认关闭、无覆盖时跳过、拒绝带权限的主题及无效 RGB，并不证明浏览器加载成功。

2026-10-11 用户实测：关闭所有 Edge 窗口后重新打开，顶部标签栏配色生效。这说明重开浏览器的路径在该用户环境中有效；是否所有后台进程退出尚未核实，也不能据此判断过渡期间的自动加载已经成功。后续可以单独研究在下一次正常启动时应用配色，避免为了配色强制关闭正在使用的浏览器。

## 回退

关闭「自动加载主题」即可恢复原有切换流程。退出试验版后，可启动原版本 `dist-dark-browser/DeskShift.exe`。

实施前的源码、原发布版、DeskShift 设置和导出的主题已保存在项目的 `backups/before-auto-theme-20261011-011131/` 中。该目录只保存在本机，不包含在发布压缩包中。备份里的 `release/DeskShift.exe` 是本次试验前的可运行版本。
