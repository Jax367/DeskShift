壁纸、搜索、常用网址。

没有时间、日期、新闻或固定宣传文案。壁纸按原图传输，搜索与常用网站保持简洁。

安装到 Edge

  1. 打开 edge://extensions，开启开发人员模式。
  2. 点击「加载已解压的扩展程序 / 加载解压缩的扩展」，选择本指南所在的 browser/edge 文件夹。
  3. 确认保留新标签页更改与「最常访问网站」权限；如浏览器关闭了扩展，请重新启用。
  4. 启动新版 DeskShift，应用一张壁纸，再打开新标签页。Chrome 用 Google 搜索，Edge 用 Bing 搜索。

这会替换浏览器的新标签页，但不改启动页地址、首页按钮地址或默认搜索引擎设置。已经加载旧版新标签页扩展时，可以在扩展页重新加载新版文件夹；此前只加载过配色主题时，请从这个新文件夹单独安装扩展。

常用网址与壁纸

点击「添加网址」手动固定网站，悬停卡片点「⋯」编辑或删除。手动网址优先，自动推荐补齐剩余位置。在添加窗口关闭「根据访问记录自动补充网址」，可只显示手动列表。自动推荐可隐藏或恢复，开关和列表保存在当前浏览器本地，重启后保留。

自动显示浏览器提供的最多 8 个最常访问网站，同域名去重，点击直接打开。没有访问记录时显示简短提示，不填入假历史网址。网站图标读取浏览器保存的网站原始 favicon；没有图标时使用浏览器默认图标，读取失败则保留空白，不生成字母或替代品牌图标，不向外部图标服务发送网址。更新后请在扩展管理页重新加载 DeskShift，允许新增的 favicon 权限。

使用 topSites 权限，不申请完整 history 权限，不将常用网址发给桌面软件或服务器。此列表由浏览器决定，可能与默认 Edge 新标签页的置顶列表不同。

壁纸从本机 127.0.0.1:47831 获取，在软件「切换设置 → 浏览器背景」可选压缩原图、亚克力模糊或抽象色块，选择后自动更新。抽象色块只保留壁纸色调，不保留画面内容。浏览器使用独立 JPEG 副本，最长边不超过 2560 像素、质量 82；桌面原图不变，页面按屏幕比例居中填充。只缓存最近一张壁纸，退出 DeskShift 后仍可显示缓存。后台标签页暂停轮询，重新激活时同步。

配色与恢复

新标签页自动同步壁纸与配色；浏览器标签栏配色另用软件的「标题栏配色指南」，需手动加载。想恢复原有新标签页时，在扩展页面停用或移除 DeskShift 新标签页扩展，再启用你原来的新标签页扩展。
