让 Chrome 跟随你的壁纸

自动同步新标签页配色

  1. 在 Chrome 地址栏输入 chrome://extensions。
  2. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
  3. 选择 DeskShift 程序旁的 browser\chrome 文件夹（本指南所在文件夹）。
  4. 保留 Chrome 提示中的新标签页更改。启动 DeskShift，选一张壁纸并点击「一键应用桌面」。
  5. 新开一个标签页，配色会在数秒内同步，背景使用纯色，不显示桌面壁纸。DeskShift 关闭窗口后仍在托盘运行。

该扩展仅访问本机 127.0.0.1:47831 和自身存储。不申请浏览记录、标签页或网站内容权限。默认不会改变网页配色或完整浏览器标签栏。

完整标签栏配色

  1. 在 DeskShift 选中壁纸，点击「导出 Chrome 完整主题」。
  2. 在 chrome://extensions 点击「加载已解压的扩展程序」，选择刚打开的主题文件夹。
  3. 每次更换壁纸后需加载对应的主题。重复导出同一主题时，可先移除旧主题再加载。

Chrome 完整主题是静态主题包，公开扩展 API 无动态修改标签栏颜色的接口。新标签页可以自动同步，完整主题需要手动安装。卸载新标签页扩展可恢复原来的新标签页；Chrome「设置 → 外观 → 主题 → 重置为默认」可恢复默认主题。
